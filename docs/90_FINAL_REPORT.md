## 2. 7단계 감사 결과 (요약 — 상세 `docs/12_deep_audit_and_upgrade.md`)

### 2.1 자금이 걸린 치명 결함 3건 (라이브가 한 번도 돌 수 없던 이유)

| # | 결함 | 증상 | 수정 |
|---|---|---|---|
| F1 | 서명 문자열이 `0x` 없이 반환되어 `sig[2:]`가 **첫 바이트를 절단** | 포크 첫 실행 `BadStrategySignature` | `_hex_signature()` 정규화 + 소비 측 `removeprefix` |
| F2 | `SENTINEL_LIVE=1`이 실제 실행기를 바꾸지 않음 | 라이브인 줄 알았는데 페이퍼 | `settings.live → ChainExecutor` |
| F3 | 비용 모델이 **수수료 이중계상 + 이탈을 비용으로 계산** | -381bp 이탈에도 “비용 461bp”로 거부 | spot 기준 impact, 왕복 = impact 합 (65.7bp) |

### 2.2 그 외 핵심 수정

- 가드가 **실제 주문의 견적**으로 판정하고 impact를 spot 기준으로 측정 — 덤프 중 청산이 막히던 역설 제거.
- 청산 규모는 포지션 가치 기준 + 볼트의 청산 상한(800 USDT) 준수, 볼트에 **직송된 기부 토큰 매도**는
  `SellExceedsPosition`으로 스왑 전 거부.
- 백테스트 캐시가 lookback을 무시해 320k 요청에 40k 결과를 반환 → 키 수정 + 창 자동 확장.
- 승률 = 승/청산, tx 해시 `0x` 정복, x402 데모 자기-락 데드락 제거.
- **메인넷 오발 방지**: 비-loopback RPC는 `SENTINEL_CONFIRM_MAINNET_TX=1` 없이 브로드캐스트 거부.

### 2.3 심사 표면 업그레이드

- **시나리오 랩**(`/api/simulate`): 이탈·크기·낙폭·킬스위치·전략 모드를 슬라이더로 바꿔 **같은 게이트**로 판정.
- **게이트 추적**(`/api/trace`): 계약과 같은 순서, 첫 실패에서 멈춤, 청산 예외는 `n/a`.
- **LLM**(`agent/narrator.py`): 서술은 하되 사실에 없는 숫자는 폐기, 제안은 정책·가드가 거부.
- **x402 chain 정산**: 목 EIP-3009 토큰으로 실제 `transferWithAuthorization` (포크 tx, gas 65,840).
- **ERC-8004 실볼트 연결**: 어댑터 검증 100 · 평판 36,144 = `vault.edgeCredibilityBps()`.
- **CI**(`ci.yml`): contracts / agent / fork 3잡.

## 6. 정직하게 밝히는 한계

- **수익성은 실증되지 않았다.** 공개 시장에서 비용 65.7bp·허들 146bp, 관측 최대 이탈 130bp →
  실제 기록 바 40개에서 거래 0건. 이는 구현 실패가 아니라 시장이 그만큼 비싸다는 측정 결과다.
- 단일 쿼트 자산(USDT)·단일 hop. WETH/WBTC는 더 얇고 비싸다(58.7 / 56.3bp at 120 USDT).
- 오라클이 창을 서빙하지 못하면 거래 중단(fail-closed), 조회 뷰는 `oracleHealthy=false`로 살아 있다.
- 소유자 키 분실 = 자금 동결(업그레이드 없음 — 의도적).
- Slither High 1건은 구조적 수용(`nonReentrant` + 불변 라우터 + 화이트리스트 + 보고/잔고 일치 강제).
- LLM은 서술·제안만 하며, 설정된 엔드포인트가 없으면 결정론적 문장으로 동작한다(데모 기본값).
